# 声部练习室｜项目交接仓库

这是“声部练习室”网页项目的可移交源码与项目资料。项目面向小型合唱团队，支持上传乐谱、识别声部旋律、钢琴播放、节拍器与练习速度调节，并包含乐谱记录和后台管理相关实现。

## 项目现状

项目已经形成可运行的网页原型，并完成多轮识谱、播放和部署恢复验收。当前交接版本的最新待办是：继续处理《道别是一件难事》识谱结果多版本保存问题，并完成回归验证。项目状态、已完成事项、运行方式及交接步骤详见 [`交接指南.md`](交接指南.md) 和 [`项目进度与未完成事项.md`](项目进度与未完成事项.md)。

## 目录

- `项目源码/working/`：应用源码、管理功能、识谱处理代码与测试。
- `项目源码/sources/`：识谱引擎补丁、依赖资料和验收用乐谱。
- `验收文档/`：阶段验收记录与复现说明。
- `SHA256SUMS.txt`：交接文件校验和清单。

## 安全与数据说明

本仓库收录的是经过筛选的交接包，不包含项目运行数据库、用户上传记录、访问令牌或本机临时文件。仓库目前是项目交接资料，不是已部署的公共在线服务；公开仓库中的代码和资料任何人均可查看。

## 开始接手

先阅读 [`交接指南.md`](交接指南.md)，再查看 `项目源码/README.md` 的运行环境与启动说明。运行时请使用自己的配置和数据目录，不要将本地密钥或数据库文件提交到仓库。
